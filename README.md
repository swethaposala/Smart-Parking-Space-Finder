# Smart Parking Space Finder

## Overview
Smart Parking Space Finder is a Flask-based web application that helps users search, reserve, and manage parking spaces efficiently.

## Features
- User Registration and Login
- Parking Slot Search
- Slot Reservation
- Booking History
- Owner Dashboard
- Parking Management

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite
